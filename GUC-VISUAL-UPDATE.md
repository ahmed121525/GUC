# GUC Visual Update

This update enhances the existing Girl Up Conquistadors site with:

- Animated atmospheric background art: grid, orbit rings, organic blobs, crosses and sparkles.
- Mouse/scroll parallax variables that move the background and hero artwork.
- Custom desktop/laptop cursor with magnetic hover ring behavior.
- Animated mobile hamburger that morphs into an X and pulses while open.
- Animated mobile navigation reveal with staggered menu items.
- Branded GUC navbar mark with layered lettering, glow, spark and arrow treatment.
- Stronger CTA buttons with gradient sweep, lift, glow and tactile hover states.
- More varied typography using Bowlby One SC, Bodoni Moda and Caveat alongside the existing fonts.
- QR code hover animation with scan beam, badge reveal and enhanced glow.
- Improved dimensionality across cards and panels.
- Archive year/month/event cards forced to high-contrast white text so they remain visible on dark backgrounds.

Changed source files:
- `src/main.tsx`
- `src/styles.css`
- `index.html`

The existing application structure, calendar data file, archive data file, Vercel API route, donation QR generation and Supabase uploader are preserved.
